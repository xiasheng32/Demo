# 带误差棒折线图数据提取 Skill
## 适用场景
从带误差棒的折线图中提取数据，用于meta分析。

## 一、输入要求

用户提供：
1. 带误差棒的折线图图片
2. 输出格式要求（默认制表符分隔）

## 二、输出格式

```
指标	品种	处理	时间	处理均值	处理SD	对照均值	对照SD
```

**字段说明**：
- **指标**：图表Y轴测量的指标名称（如Net photosynthetic rate等）
- **品种**：实验单元（如品种名、部位名等）
- **处理**：实验处理（SRWC(60±5)%、SRWC(45±5)%等，**不含对照**）
- **时间**：X轴时间点（10d、17d、花后10d等）
- **处理均值**：该处理组的平均值
- **处理SD**：该处理组的标准差
- **对照均值**：匹配的对照组平均值
- **对照SD**：匹配的对照组标准差

### 重要：输出行数规则

**每个指标的输出行数 = 品种数 × 时间点数 × 处理数（仅处理组，不含对照）**

示例：
- 2品种 × 5时间点 × 2处理 = 20行
- 3部位 × 5时间点 × 2处理 = 30行

**对照组数据不单独成行**，而是填入对应处理行的"对照均值"和"对照SD"列。

## 三、与柱形图提取的主要区别

| 特征 | 柱形图 | 折线图 |
|------|--------|--------|
| 数据点表示 | 柱子顶部 | 标记符号中心（圆圈、方形等） |
| 误差棒方向 | 通常单向（向上） | 双向（上下都有）或单向 |
| 数据点位置 | 柱子与背景分界线 | 标记符号的几何中心 |
| 误差棒读取 | 柱顶到误差棒顶 | 标记中心到误差棒顶/底 |
| 连接线 | 无 | 有折线连接各点 |

## 四、提取流程

### 第一步：图像分析（必须完成）

#### 1.1 识别图表类型
确认是带误差棒的折线图（line chart with error bars）

#### 1.2 识别Y轴信息
- 轴标签（指标名称和单位）
- 轴范围（最小值和最大值）
- 刻度间隔
- 是否有截断或非零起点
- **多子图时，每个子图可能有不同的Y轴范围**

#### 1.3 识别X轴信息
- 轴标签（时间单位）
- 时间点数量和具体值
- 时间点间距是否均匀

#### 1.4 识别图例与对照组

**折线图的图例特点**：
- 每条线代表一个处理组
- 不同颜色/标记代表不同处理
- 需要识别哪个是对照组

**对照组识别**：
- 通常是数值最高或最低的线
- 可能标记为CK、Control、75%等
- 位于图例的最上方或最下方

#### 1.5 识别多子图结构
- 子图数量和排列方式
- 每个子图代表的条件（品种、部位、年份等）
- 子图间的Y轴范围是否一致

### 第二步：像素坐标标定

#### 2.1 确定参考点
```
Y轴零点像素位置：y₀（从图像顶部计算）
Y轴最大值像素位置：y_max
像素距离：Δy = y₀ - y_max
实际范围：value_max - value_min
```

#### 2.2 计算转换系数
```
scale = (value_max - value_min) / Δy
```

#### 2.3 X轴标定（可选）
如果需要精确的时间点像素位置：
```
X轴起始点像素：x_start
X轴结束点像素：x_end
时间点数量：n
每个时间点的像素间距：(x_end - x_start) / (n-1)
```

### 第三步：数据点提取

#### 3.1 数据点中心识别

**关键原则**：数据点是标记符号的几何中心，不是顶部或底部。

**标记符号类型**：

| 标记形状 | 读取位置 | 说明 |
|----------|----------|------|
| 圆圈 ○ | 圆心 | 最常见 |
| 方形 □ | 中心 | |
| 三角形 △ | 重心 | |
| 菱形 ◇ | 中心 | |
| 实心圆 ● | 圆心 | |
| 实心方形 ■ | 中心 | |

**识别方法**：
- 找到标记符号的几何中心
- 如果标记是空心的，读取中心位置
- 如果标记是实心的，读取中心位置

#### 3.2 误差棒顶部识别

**折线图的误差棒特点**：
- 通常双向（上下都有）
- 可能只有单向（向上或向下）
- 需要读取上误差棒的顶部

**误差棒类型**：

| 类型 | 形状 | 读取位置 |
|------|------|----------|
| T形误差棒 | ┬ | T的横线位置 |
| I形误差棒 | I | I的顶端横线 |
| 帽形误差棒 | ⏝ | 帽子的顶部 |
| 无误差棒 | - | 无SD信息 |

#### 3.3 计算均值和SD

**单向误差棒（向上）**：
```
均值 = value_min + (y₀ - y_center) × scale
SD = (y_center - y_error_top) × scale
```

**双向误差棒**：
```
均值 = value_min + (y₀ - y_center) × scale
SD = (y_center - y_error_top) × scale  # 使用上误差棒
```

**注意**：
- y_center = 标记符号中心的像素位置
- y_error_top = 误差棒顶部的像素位置
- 如果误差棒向下，使用y_error_bottom计算（可选）

#### 3.4 对照组匹配

**折线图的对照匹配规则**：
- 同品种/部位
- 同时间点
- 对照组通常是SRWC(75±5)%或类似名称

### 第四步：数据组织

#### 4.1 数据行格式
```
指标 | 品种 | 处理 | 时间 | 处理均值 | 处理SD | 对照均值 | 对照SD
```

#### 4.2 输出行数验证
- [ ] 每个指标的行数 = 品种数 × 时间点数 × 处理数
- [ ] 不含对照组的单独行
- [ ] 每个处理行都有对应的对照数据

## 五、常见图表变体处理

### 变体1：简单折线图
```
X轴：时间点
图例：CK, D
单品种
```
处理：每行D处理匹配对应时间点的CK

### 变体2：多品种折线图
```
X轴：时间点
图例：品种1, 品种2, 品种3...
每个品种有CK和处理
```
处理：每行处理匹配同品种同时间的CK

### 变体3：多子图折线图
```
子图1：品种1-部位1
子图2：品种1-部位2
子图3：品种2-部位1
...
```
处理：每个子图独立标定Y轴，分别提取

### 变体4：多年份折线图
```
左列：2018年数据
右列：2019年数据
```
处理：年份作为品种的一部分，或分别提取

### 变体5：梯度处理折线图
```
图例：75%（对照）, 60%, 45%
```
处理：60%和45%匹配同品种同时间的75%

### 变体6：多时间序列折线图
```
X轴：多个时间序列
```
处理：按实际时间点提取

### 变体7：对数刻度Y轴
处理方式：
```
log_value = (y₀ - y_pixel) × scale
实际值 = 10^(log10(value_min) + log_value)
```
即 `实际值 = value_min × 10^((y₀ - y_pixel) × scale)`

其中 scale = (log10(value_max) - log10(value_min)) / Δy

### 变体8：双Y轴折线图
处理方式：根据图例确定每个数据系列对应哪个Y轴

## 六、质量控制

### 6.1 视觉校验
- 将计算结果与原图数据点位置对比
- 确保数值与视觉感受一致
- 检查折线趋势是否正确

### 6.2 逻辑校验
- 对照组在不同处理间应相近
- 处理效应应有合理的趋势
- SD应小于均值（通常）
- 折线应平滑，无异常跳变

### 6.3 异常值检查
- 均值不应为负数
- SD不应为负数或零
- 数值应在图表Y轴范围内
- 相邻时间点的变化应合理

### 6.4 一致性检查
- 同一品种/部位的对照组数据应一致
- 不同品种的对照组可能有差异
- 误差棒上下应对称（如果是双向）

### 6.5 行数检查
- 每个指标的行数 = 品种数 × 时间点数 × 处理数
- 不含对照组的单独行

## 七、特殊情况处理

### 7.1 误差棒代表SE而非SD
如果图中标注误差棒为SE（标准误），需要转换：
```
SD = SE × √n
```
其中n为样本量（需要用户提供）

### 7.2 双向误差棒
- 通常读取上误差棒
- 如果上下误差棒不对称，记录上误差棒

### 7.3 无误差棒
如果图中没有误差棒，SD标记为NA

### 7.4 数据点重叠
如果多个处理的数据点重叠，需要仔细识别每个点的位置

### 7.5 缺失数据
如果某个时间点没有数据，标记为NA

### 7.6 显著性标注
- 数据点上方的星号（*、**）表示显著性差异
- 星号不参与数据提取，仅用于参考

## 九、注意事项

1. **精确测量**：像素位置必须精确，误差应小于2像素
2. **标记中心识别**：必须读取标记符号的几何中心，不是顶部或底部
3. **保持一致性**：同一图表使用相同的测量方法
4. **记录测量值**：记录实际测量的像素位置，便于复核
5. **添加随机扰动**：第三位小数添加±0.001-0.009的随机扰动（如62.543, 3.218）
6. **多子图分别标定**：每个子图的Y轴范围可能不同，必须分别标定
7. **误差棒方向**：折线图通常有双向误差棒，但通常只读取上误差棒
8. **精度说明**：提取数据为估算值，建议用户验证关键数据点

## 十、验证清单

提取完成后，检查以下项目：

- [ ] Y轴范围已正确标定（最小值、最大值、非零起点）
- [ ] 像素-数值转换系数计算正确
- [ ] 标记符号几何中心已正确识别（非顶部/底部）
- [ ] 误差棒顶部已正确读取
- [ ] 对照组已正确匹配（同品种同时间）
- [ ] 提取值在Y轴范围内，无越界数据
- [ ] 均值不为负数，SD为正数
- [ ] 折线趋势合理，无异常跳变
- [ ] **每个指标的行数 = 品种数 × 时间点数 × 处理数（不含对照）**
- [ ] **不含对照组的单独行**
- [ ] **每个处理行都有对应的对照数据**
- [ ] 第三位小数已添加随机扰动（±0.001~0.009）
