# 带误差棒折线图数据提取验证清单

## 一、提取前检查

- [ ] 图像清晰可读
- [ ] Y轴范围和刻度清晰可见
- [ ] X轴时间点清晰可见
- [ ] 图例清晰可辨
- [ ] 所有数据点和误差棒清晰可见
- [ ] **已识别对照组的名称和位置**

## 二、图像分析检查

### 2.1 Y轴信息
- [ ] 指标名称和单位已识别
- [ ] Y轴范围已确认（最小值和最大值）
- [ ] 刻度间隔已确认
- [ ] 是否有非零起点
- [ ] **多子图时，每个子图独立标定**

### 2.2 X轴信息
- [ ] 时间单位已识别
- [ ] 时间点数量已确认
- [ ] 具体时间点值已列出
- [ ] 时间点间距是否均匀

### 2.3 图例与对照
- [ ] 每条线对应的处理已识别
- [ ] **对照组已识别（CK/75%等）**
- [ ] **对照匹配规则已确定**
- [ ] 对照组的名称和位置已记录

### 2.4 多子图结构
- [ ] 子图数量和排列方式已识别
- [ ] 每个子图代表的条件已明确
- [ ] 子图间的Y轴范围是否一致

## 三、像素标定检查

- [ ] Y轴零点像素位置测量正确
- [ ] Y轴最大值像素位置测量正确
- [ ] 转换系数计算正确
- [ ] **多子图时，每个子图独立标定**

## 四、数据提取检查

### 4.1 数据点中心测量
- [ ] 正确识别了标记符号类型
- [ ] 读取了标记符号的几何中心（不是顶部或底部）
- [ ] 所有数据点都已测量
- [ ] 测量值在合理范围内

### 4.2 误差棒测量
- [ ] 正确识别了误差棒类型
- [ ] 读取了上误差棒的顶部（不是下误差棒）
- [ ] 所有误差棒都已测量
- [ ] 误差棒长度合理

### 4.3 对照组匹配
- [ ] **同品种/部位的对照已匹配**
- [ ] **同时间点的对照已匹配**
- [ ] 对照数据已填入正确位置
- [ ] 无遗漏的对照匹配

## 五、数据格式检查

### 5.1 列格式
- [ ] 使用制表符分隔
- [ ] 列顺序正确：指标、品种、处理、时间、处理均值、处理SD、对照均值、对照SD
- [ ] 数值保留3位小数

### 5.2 行数验证
- [ ] **每个指标的行数 = 品种数 × 时间点数 × 处理数**
- [ ] **不含对照组的单独行**
- [ ] 每个处理行都有对应的对照数据

### 5.3 数据内容
- [ ] 所有均值为正数
- [ ] 所有SD为正数
- [ ] SD小于均值（通常）
- [ ] 数值在Y轴范围内
- [ ] 折线趋势平滑，无异常跳变

## 六、特殊情况检查

- [ ] 误差棒类型确认（SD还是SE？）
- [ ] 如果是SE，是否已转换为SD？
- [ ] 样本量是否已记录？
- [ ] 是否有缺失数据？
- [ ] 星号标注已忽略

## 七、最终确认

- [ ] 数据已备份
- [ ] 提取过程已记录
- [ ] 与原图对比无明显差异
- [ ] 符合生物学规律
- [ ] **行数验证通过**

## 八、对照匹配速查表

| 图表类型 | 对照名称 | 匹配规则 |
|----------|----------|----------|
| 简单CK vs D | CK | 同一时间点的CK |
| 多品种各自CK | CK | 同一品种的CK |
| 梯度处理 | 75% | 60%/45%→同品种同时间的75% |
| 多部位 | CK | 同一部位同时间的CK |
| 多子图 | CK | 每个子图独立匹配 |
| 多年份 | CK | 同年份同品种同时间的CK |

## 九、常见错误

| 错误类型 | 错误描述 | 正确做法 |
|----------|----------|----------|
| 数据点识别错误 | 将标记顶部当作中心 | 读取标记符号的几何中心 |
| 误差棒读取错误 | 读取下误差棒 | 读取上误差棒的顶部 |
| 对照匹配错误 | 跨年份或跨部位匹配 | 同年份同部位同时间匹配 |
| 行数错误 | 包含了对照组的行 | 不含对照组的单独行 |
| Y轴标定错误 | 多子图使用相同标定 | 每个子图独立标定 |
