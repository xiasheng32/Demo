# 表格数据提取验证清单

## 一、提取前检查

- [ ] 图像清晰可读
- [ ] 表格结构完整
- [ ] 所有数值清晰可见
- [ ] 表头信息完整
- [ ] **已识别对照组的名称和位置**

## 二、表格分析检查

### 2.1 表格结构
- [ ] 行数和列数已确认
- [ ] 表头层级已识别
- [ ] 合并单元格位置已标记
- [ ] 品种列位置已确认
- [ ] 处理列位置已确认

### 2.2 指标信息
- [ ] 所有指标名称已列出
- [ ] 每个指标的单位已确认
- [ ] 指标数量已确认

### 2.3 数据格式
- [ ] 均值±SD格式已识别
- [ ] 是否有显著性字母
- [ ] 小数位数已确认
- [ ] 是否需要SE到SD的转换

## 三、数据解析检查

### 3.1 数值提取
- [ ] 正确解析了±符号
- [ ] 均值提取正确
- [ ] SD提取正确
- [ ] 显著性字母已忽略
- [ ] 空格已处理

### 3.2 合并单元格
- [ ] 合并范围已识别
- [ ] 合并内容已填充到所有相关行

### 3.3 缺失数据
- [ ] 空单元格已标记为NA
- [ ] 缺失值已正确处理

## 四、对照组匹配检查

- [ ] **对照组已识别（Control、CK等）**
- [ ] **同品种的对照已匹配**
- [ ] **同组织的对照已匹配**
- [ ] **同时间点的对照已匹配**
- [ ] 对照数据已填入正确位置

## 五、数据格式检查

### 5.1 列格式
- [ ] 使用制表符分隔
- [ ] 列顺序正确：指标、品种、处理、时间、处理均值、处理SD、对照均值、对照SD
- [ ] 数值保留3位小数

### 5.2 行数验证
- [ ] **每个指标的行数 = 品种数 × 处理数**
- [ ] **不含对照组的单独行**
- [ ] 每个处理行都有对应的对照数据

### 5.3 数据内容
- [ ] 所有均值为正数（通常）
- [ ] 所有SD为正数
- [ ] SD小于均值（通常）
- [ ] 数值在合理范围内

## 六、特殊情况检查

- [ ] 误差棒类型确认（SD还是SE？）
- [ ] 如果是SE，是否已转换为SD？
- [ ] 样本量是否已记录？
- [ ] 单位是否正确？
- [ ] 合并单元格是否已处理？

## 七、最终确认

- [ ] 数据已备份
- [ ] 提取过程已记录
- [ ] 与原表对比无明显差异
- [ ] 符合生物学规律
- [ ] **行数验证通过**

## 八、对照匹配速查表

| 表格类型 | 对照名称 | 匹配规则 |
|----------|----------|----------|
| 简单对照 vs 处理 | Control | 同品种的Control |
| 多品种 | Control | 同品种的Control |
| 多组织 | Control | 同组织同品种的Control |
| 多时间点 | Control | 同品种同时间的Control |

## 九、常见错误

| 错误类型 | 错误描述 | 正确做法 |
|----------|----------|----------|
| 格式解析错误 | 将字母当作SD | 忽略所有显著性字母 |
| 对照匹配错误 | 跨组织匹配 | 同组织同品种匹配 |
| 合并单元格错误 | 未填充合并内容 | 识别合并范围并填充 |
| SE/SD混淆 | 未进行转换 | 检查表头并转换 |
| 行数错误 | 包含了对照组的行 | 不含对照组的单独行 |
