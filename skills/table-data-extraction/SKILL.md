# 表格数据提取 Skill（均值±SD格式）
## 适用场景
从学术论文表格中提取均值±SD格式的数据，用于meta分析。

## 一、输入要求

用户提供：
1. 包含均值±SD数据的表格图片
2. 输出格式要求（默认制表符分隔）

## 二、输出格式

```
指标	品种	处理	时间	处理均值	处理SD	对照均值	对照SD
```

**字段说明**：
- **指标**：列标题中的指标名称（如SOD、MDA、POD等）
- **品种**：行中的品种/基因型信息（如YT93-159、YZ05-51等）
- **处理**：实验处理（Drought、LD、MD等，**不含对照**）
- **时间**：取样时间点（如有），否则标记为NA
- **处理均值**：该处理组的平均值
- **处理SD**：该处理组的标准差
- **对照均值**：匹配的对照组平均值
- **对照SD**：匹配的对照组标准差

### 重要：输出行数规则

**每个指标的输出行数 = 品种数 × 处理数（仅处理组，不含对照）**

示例：
- 2品种 × 1处理 = 2行
- 3品种 × 2处理 = 6行

**对照组数据不单独成行**，而是填入对应处理行的"对照均值"和"对照SD"列。

## 三、表格数据的特殊性

### 3.1 与图表数据的区别

| 特征 | 图表数据 | 表格数据 |
|------|----------|----------|
| 数据位置 | 需要像素测量 | 直接从单元格读取 |
| 格式 | 数字 | 均值±SD±显著性字母 |
| 精度 | 依赖测量精度 | 精确数值 |
| 提取速度 | 较慢 | 较快 |
| **随机数** | **可添加随机扰动** | **必须使用原数据** |

### 3.2 表格数据的常见格式

**格式1：均值±SD**
```
995.36±5.06
```

**格式2：均值±SD±显著性字母**
```
995.36±5.06c
995.36±5.06±c
```

**格式3：均值(SD)**
```
995.36(5.06)
```

**格式4：均值±SE**
```
995.36±2.26
```
注：如果是SE，需要转换为SD

**格式5：仅均值+字母（无SD）**
```
12.60 a
```
注：SD标记为NA

### 3.3 表格结构类型

**类型1：简单表格**
```
品种 | 处理 | 指标1 | 指标2 | ...
```

**类型2：多级表头**
```
| 指标1 | 指标2 | ...
| 均值±SD | 均值±SD | ...
```

**类型3：合并单元格**
```
组织 | 品种 | 处理 | 指标1 | ...
叶片 | YT93 | 对照 | ...
     |      | 干旱 | ...
```

**类型4：嵌套表头**
```
| 超氧化物歧化酶(SOD) | 丙二醛(MDA) | ...
| /(U·g⁻¹) | /(nmol·g⁻¹) | ...
```

## 四、提取流程

### 第一步：表格分析（必须完成）

#### 1.1 识别表格结构
- 表格标题
- 行数和列数
- 表头层级
- 合并单元格位置

#### 1.2 识别列信息
- 品种列位置
- 处理列位置
- 指标列位置
- 每个指标的单位

#### 1.3 识别行信息
- 品种名称
- 处理名称
- 对照组标识（Control、CK等）

#### 1.4 识别数据格式
- 均值±SD格式
- 是否有显著性字母
- 小数位数

### 第二步：数据解析

#### 2.1 解析均值±SD格式

**格式1：均值±SD**（无字母）
```
995.36±5.06
→ 均值 = 995.36, SD = 5.06
```

**格式2：均值±SD+字母**
```
995.36±5.06c
→ 均值 = 995.36, SD = 5.06（忽略字母c）
```

**格式3：均值±SD±字母**
```
995.36±5.06±c
→ 均值 = 995.36, SD = 5.06（忽略±c）
```

**格式4：空格分隔**
```
995.36 ± 5.06c
→ 均值 = 995.36, SD = 5.06（忽略空格和字母）
```

**格式5：仅均值+字母（无SD）**
```
12.60 a
→ 均值 = 12.60, SD = NA（无SD数据）
```

#### 2.2 提取数值

**正则表达式**：
```python
# 匹配均值±SD格式
pattern = r'(\d+\.?\d*)\s*±\s*(\d+\.?\d*)[a-zA-Z]*'

# 匹配均值(SD)格式
pattern = r'(\d+\.?\d*)\s*\(\s*(\d+\.?\d*)\s*\)'
```

**提取步骤**：
1. 找到±符号
2. ±左边是均值
3. ±右边是SD（忽略字母）
4. 忽略所有显著性字母

### 第三步：对照组匹配

#### 3.1 对照匹配规则

**核心原则：对照组必须与处理组在所有非处理因素上保持一致**

匹配维度：
1. **同品种**：同一品种/基因型
2. **同组织**：同一组织/部位（如有）
3. **同时间**：同一时间点（如有）

#### 3.2 对照组识别

**对照组名称可能多样**：
- Control、CK、对照
- 正常水分、Normal
- 0处理、未处理

### 第四步：数据组织

#### 4.1 数据行格式
```
指标 | 品种 | 处理 | 时间 | 处理均值 | 处理SD | 对照均值 | 对照SD
```

#### 4.2 输出行数验证
- [ ] 每个指标的行数 = 品种数 × 处理数
- [ ] 不含对照组的单独行
- [ ] 每个处理行都有对应的对照数据

## 五、常见表格类型处理

### 类型1：简单对照 vs 处理
```
品种 | 处理 | 指标
YT93 | 对照 | 995.36±5.06c
YT93 | 干旱 | 706.79±13.47d
```
处理：每行D处理匹配同品种的Control

### 类型2：多品种×处理
```
品种 | 处理 | 指标1 | 指标2 | ...
YT93 | 对照 | ... | ... | ...
YT93 | 干旱 | ... | ... | ...
YZ05 | 对照 | ... | ... | ...
YZ05 | 干旱 | ... | ... | ...
```
处理：每行处理匹配同品种的对照

### 类型3：多组织×品种×处理
```
组织 | 品种 | 处理 | 指标
叶片 | YT93 | 对照 | ...
叶片 | YT93 | 干旱 | ...
叶片 | YZ05 | 对照 | ...
叶片 | YZ05 | 干旱 | ...
根系 | YT93 | 对照 | ...
根系 | YT93 | 干旱 | ...
```
处理：每行处理匹配同组织同品种的对照

### 类型4：多时间点
```
品种 | 时间 | 处理 | 指标
YT93 | 0d | 对照 | ...
YT93 | 0d | 干旱 | ...
YT93 | 7d | 对照 | ...
YT93 | 7d | 干旱 | ...
```
处理：每行处理匹配同品种同时间的对照

### 类型5：嵌套表头
```
| SOD | MDA | POD | ...
| /(U·g⁻¹) | /(nmol·g⁻¹) | /(U·g⁻¹) | ...
```
处理：提取指标名称和单位

## 六、质量控制

### 6.1 数值校验
- 均值应为正数（通常）
- SD应为正数
- SD应小于均值（通常）
- 数值应在合理范围内

### 6.2 一致性检查
- 同一品种的对照组数据应一致
- 不同品种的对照组可能有差异
- 显著性字母应合理

### 6.3 行数检查
- 每个指标的行数 = 品种数 × 处理数
- 不含对照组的单独行

### 6.4 格式检查
- 使用制表符分隔
- 数值保留3位小数
- 无多余空格

## 七、特殊情况处理

### 7.1 误差棒代表SE而非SD
如果表头标注为SE（标准误），需要转换：
```
SD = SE × √n
```
其中n为样本量（需要用户提供）

### 7.2 合并单元格
- 识别合并单元格的范围
- 将合并内容填充到所有相关行

### 7.3 缺失数据
如果单元格为空或标记为-，标记为NA

### 7.4 显著性字母
- 字母不参与数据提取
- 只提取数值部分

### 7.5 单位处理
- 单位从表头提取
- 记录每个指标的单位

## 九、注意事项

1. **仔细解析**：均值±SD格式可能有变化，需要仔细识别
2. **忽略字母**：显著性字母不参与数据提取
3. **检查单位**：确保提取的数据单位正确
4. **处理合并单元格**：识别合并范围并正确填充
5. **验证数值**：确保提取的数值在合理范围内
6. **不使用随机数**：表格数据必须使用原始精确数值，不添加随机扰动
