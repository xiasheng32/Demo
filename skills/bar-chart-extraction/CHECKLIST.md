# 数据提取验证清单

## 一、提取前检查

- [ ] 图像清晰可读
- [ ] Y轴范围和刻度清晰可见
- [ ] 图例清晰可辨
- [ ] 所有柱子和误差棒清晰可见
- [ ] **已识别对照组的名称和位置**

## 二、图像分析检查

### 2.1 Y轴信息
- [ ] 指标名称和单位已识别
- [ ] Y轴范围已确认（最小值和最大值）
- [ ] 刻度间隔已确认
- [ ] 是否有非零起点
- [ ] **多子图时，每个子图独立标定**

### 2.2 X轴分组
- [ ] 分组方式已识别（按时间/品种/日期/生育期等）
- [ ] 所有分组标签已列出
- [ ] 分组层级已明确（一级/二级分组）

### 2.3 图例与对照
- [ ] 每个颜色/图案对应的处理已识别
- [ ] **对照组已识别（CK/T0/80%等）**
- [ ] **对照匹配规则已确定**
- [ ] 对照组的名称和位置已记录

## 三、像素标定检查

- [ ] Y轴零点像素位置测量正确
- [ ] Y轴最大值像素位置测量正确
- [ ] 转换系数计算正确
- [ ] **多子图时，每个子图独立标定**

## 四、数据提取检查

### 4.1 柱顶测量
- [ ] 区分了柱顶和误差棒顶部
- [ ] 所有柱子都已测量
- [ ] 测量值在合理范围内
- [ ] 填充图案的柱子识别正确

### 4.2 误差棒测量
- [ ] 正确识别了误差棒类型
- [ ] 所有误差棒都已测量
- [ ] 误差棒长度合理

### 4.3 对照组匹配
- [ ] **同品种/部位的对照已匹配**
- [ ] **同时间/日期/生育期的对照已匹配**
- [ ] 对照数据已填入正确位置
- [ ] 无遗漏的对照匹配

## 五、数据格式检查

### 5.1 列格式
- [ ] 使用制表符分隔
- [ ] 列顺序正确：指标、品种、处理、时间、处理均值、处理SD、对照均值、对照SD
- [ ] 数值保留3位小数

### 5.2 行数验证
- [ ] **每个指标的行数 = 品种数 × 时间点数 × 处理数**
- [ ] **不含对照组的单独行**
- [ ] 每个处理行都有对应的对照数据

### 5.3 数据内容
- [ ] 所有均值为正数
- [ ] 所有SD为正数
- [ ] SD小于均值（通常）
- [ ] 数值在Y轴范围内

## 六、特殊情况检查

- [ ] 误差棒类型确认（SD还是SE？）
- [ ] 如果是SE，是否已转换为SD？
- [ ] 样本量是否已记录？
- [ ] 是否有缺失数据？
- [ ] 柱顶的字母标注已忽略

## 七、最终确认

- [ ] 数据已备份
- [ ] 提取过程已记录
- [ ] 与原图对比无明显差异
- [ ] 符合生物学规律
- [ ] **行数验证通过**

## 八、对照匹配速查表

| 图表类型 | 对照名称 | 匹配规则 |
|----------|----------|----------|
| 简单CK vs D | CK | 同一时间点的CK |
| 多品种各自CK | CK | 同一品种的CK |
| 多部位各自CK | CK | 同一部位的CK |
| 多时间对照 | CK-0, CK-7, CK-14 | DS-7→CK-7，DS-14→CK-14 |
| 多子图 | CK | 每个子图独立匹配 |
| 梯度处理 | T0 | T1-T4→同品种同时间的T0 |
| 百分比处理 | 80% | 50%/30%→同品种同生育期的80% |
| 复水处理 | CK-14 | RW-14→同品种同时间的CK-14 |

## 九、常见错误

| 错误类型 | 错误描述 | 正确做法 |
|----------|----------|----------|
| 对照匹配错误 | DS-7匹配到CK-14 | DS-7应匹配CK-7 |
| 行数错误 | 包含了对照组的行 | 不含对照组的单独行 |
| Y轴标定错误 | 多子图使用相同标定 | 每个子图独立标定 |
| 柱顶识别错误 | 将误差棒顶当作柱顶 | 区分柱顶和误差棒顶 |
| 对照组遗漏 | 未匹配对照数据 | 每个处理行都有对照 |
