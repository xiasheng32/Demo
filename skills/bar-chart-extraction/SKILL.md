# 带误差棒柱形图数据提取 Skill
## 适用场景
从带误差棒的柱形图中提取数据，用于meta分析。

## 一、输入要求

用户提供：
1. 带误差棒的柱形图图片
2. 输出格式要求（默认制表符分隔）

## 二、输出格式

```
指标	品种	处理	时间	处理均值	处理SD	对照均值	对照SD
```

**字段说明**：
- **指标**：图表Y轴测量的指标名称（如MDA、Pro、Fv/Fm、Relative Water Content等）
- **品种**：实验单元（如品种名HN44、部位Flag leaf、品种B01等）
- **处理**：实验处理（LD、MD、SD、D、T1、50%、30%等，**不含对照组**）
- **时间**：实验条件（时间点0d/7d、日期06-21、生育期Elongation stage等）
- **处理均值**：该处理组的平均值
- **处理SD**：该处理组的标准差
- **对照均值**：匹配的对照组平均值
- **对照SD**：匹配的对照组标准差

### 重要：输出行数规则

**每个指标的输出行数 = 品种数 × 时间点数 × 处理数（仅处理组，不含对照）**

示例：
- 5个品种 × 1个时间点 × 1个处理 = 5行
- 2个品种 × 5个时间点 × 3个处理 = 30行
- 6个品种 × 2个生育期 × 2个处理 = 24行

**对照组数据不单独成行**，而是填入对应处理行的"对照均值"和"对照SD"列。

## 三、提取流程

### 第一步：图像分析（必须完成）

#### 1.1 识别图表类型
确认是带误差棒的柱形图（bar chart with error bars）

#### 1.2 识别Y轴信息
- 轴标签（指标名称和单位）
- 轴范围（最小值和最大值）
- 刻度间隔
- 是否有截断或非零起点
- **多子图时，每个子图可能有不同的Y轴范围，必须分别标定**

#### 1.3 识别X轴分组结构

**X轴分组方式多样，需要仔细识别**：

| 分组方式 | 示例 | 说明 |
|----------|------|------|
| 按时间分组 | 0d, 1d, 3d, 5d, 7d | 最常见 |
| 按品种分组 | B01, M01, M04, DS10 | X轴标签为品种名 |
| 按日期分组 | 06-21, 07-03, 08-08 | 按具体日期 |
| 按生育期分组 | 苗期, 块茎形成期, 块茎膨大期 | 按发育阶段 |
| 按处理分组 | CK, D（2组） | 简单对比 |
| 按时间+处理分组 | 干旱胁迫7d, 复水后2d | 二级分组 |

#### 1.4 识别图例与对照组

**关键：确定每个处理组对应的对照组**

**对照组名称可能多样**：
- CK、Control、CK-0、T0
- 80%、70%~75% FC
- 其他表示正常条件的名称

**常见对照匹配模式**：

| 模式 | 示例 | 匹配规则 |
|------|------|----------|
| 简单对照 | CK vs D | 同一时间点的CK |
| 多时间对照 | CK-0, CK-7, CK-14 | DS-7→CK-7，DS-14→CK-14 |
| 多品种对照 | 每个品种有自己的CK | 同一品种的CK |
| 多部位对照 | 每个部位有自己的CK | 同一部位的CK |
| 百分比对照 | 80% vs 50% vs 30% | 同品种同时间的80% |
| 梯度对照 | T0 vs T1/T2/T3/T4 | 同品种同时间的T0 |

#### 1.5 识别多子图结构

**多子图需要独立处理**：
- 每个子图可能有不同的Y轴范围
- 每个子图可能代表不同指标或不同品种/部位
- 必须分别标定每个子图的像素-数值转换关系

### 第二步：像素坐标标定

#### 2.1 确定参考点
```
Y轴零点像素位置：y₀（从图像顶部计算）
Y轴最大值像素位置：y_max
像素距离：Δy = y₀ - y_max
实际范围：value_max - value_min
```

#### 2.2 计算转换系数
```
scale = (value_max - value_min) / Δy
```

#### 2.3 处理非零起点
如果Y轴不从0开始：
```
实际值 = value_min + (y₀ - y_pixel) × scale
```

### 第三步：数据点提取

#### 3.1 柱形顶部识别

**关键原则**：柱形顶部是指柱子本身的顶部，不包括误差棒。

```
        ← 误差棒顶部（读取SD用）
        ┃
        ┃  ← 误差棒
        ┃
████████████  ← 柱形顶部（读取均值用）
████████████
████████████
```

识别方法：
- 找到柱形与背景的分界线
- 如果有填充图案（斜线、网格等），识别图案的上边界
- 如果柱顶有字母标注，字母下方即为柱顶
- 如果柱顶有数字标注，数字下方即为柱顶

#### 3.2 误差棒顶部识别

误差棒类型可能有：

| 类型 | 形状 | 读取位置 |
|------|------|----------|
| T形误差棒 | T | T的横线位置 |
| I形误差棒 | I | I的顶端横线 |
| 箭头误差棒 | ↑ | 箭头尖端 |
| 方形误差棒 | □ | 方形顶部 |
| 圆形误差棒 | ● | 圆形顶部 |

#### 3.3 计算均值和SD

```
均值 = value_min + (y₀ - y_bar) × scale
SD = (y_bar - y_error) × scale
```

其中：
- y_bar = 柱形顶部像素位置
- y_error = 误差棒顶部像素位置

### 第四步：对照组匹配与数据组织

#### 4.1 对照匹配规则

**核心原则：对照组必须与处理组在所有非处理因素上保持一致**

匹配维度（按优先级）：
1. **同品种**：同一品种/部位/基因型
2. **同时间**：同一时间点/日期/生育期
3. **同条件**：同一实验条件

**对照匹配速查表**：

| 处理组 | 对照组 | 匹配条件 |
|--------|--------|----------|
| D（干旱） | CK | 同品种同时间 |
| DS-7 | CK-7 | 同品种同时间 |
| DS-14 | CK-14 | 同品种同时间 |
| T1/T2/T3/T4 | T0 | 同品种同时间 |
| 50%/30% | 80% | 同品种同时间 |
| LD/MD/SD | CK | 同品种同时间 |

#### 4.2 数据组织

对每个处理组数据行：
```
指标 | 品种 | 处理 | 时间 | 处理均值 | 处理SD | 对照均值 | 对照SD
     |      |      |      |          |        | ↑匹配的对照 |
```

#### 4.3 输出行数验证

提取完成后验证：
- [ ] 每个指标的行数 = 品种数 × 时间点数 × 处理数
- [ ] 不含对照组的单独行
- [ ] 每个处理行都有对应的对照数据

## 四、常见图表变体处理

### 变体1：简单时间序列（X轴按时间分组）
```
X轴：0d, 6d, 15d, 24d, 28d
图例：CK, D
```
处理：每行D处理匹配对应时间点的CK

### 变体2：多品种×时间（图例为品种）
```
X轴：时间点
图例：品种1, 品种2, 品种3...
每个品种有CK和处理
```
处理：每行处理匹配同品种同时间的CK

### 变体3：多部位×处理（图例为处理组）
```
X轴：部位1, 部位2, 部位3
每个部位内有多个处理组
图例：CK-0, CK-7, DS-7, CK-14, DS-14, RW-14
```
处理：
- DS-7 → 同部位的CK-7
- DS-14 → 同部位的CK-14
- RW-14 → 同部位的CK-14

### 变体4：多子图（每个子图独立）
```
子图a：品种1
子图b：品种2
子图c：品种3
...
```
处理：每个子图独立标定Y轴，分别提取

### 变体5：X轴按品种分组
```
X轴：品种1, 品种2, 品种3, 品种4
图例：CK, D
2个生育期分别显示
```
处理：每个品种每个生育期的D处理匹配对应CK

### 变体6：X轴按日期/生育期分组
```
X轴：06-21, 07-03, 07-15...（日期）
或：苗期, 块茎形成期, 块茎膨大期...
图例：T0, T1, T2, T3, T4
```
处理：每个日期/生育期的T1-T4处理匹配对应T0

### 变体7：梯度处理（百分比）
```
图例：80%（对照）, 50%, 30%
```
处理：50%和30%匹配同品种同时间的80%

### 变体8：堆叠柱形图
处理方式：只读取最顶层的柱子高度（不含误差棒）

### 变体9：水平柱形图
处理方式：X轴变为数值轴，Y轴变为分组轴

### 变体10：对数刻度
处理方式：
```
log_value = (y₀ - y_pixel) × scale
实际值 = 10^(log10(value_min) + log_value)
```
即 `实际值 = value_min × 10^((y₀ - y_pixel) × scale)`

其中 scale = (log10(value_max) - log10(value_min)) / Δy

### 变体11：双Y轴
处理方式：根据图例确定每个数据系列对应哪个Y轴

## 五、质量控制

### 5.1 视觉校验
- 将计算结果与原图柱形高度对比
- 确保数值与视觉感受一致

### 5.2 逻辑校验
- 对照组在不同处理间应相近
- 处理效应应有合理的趋势（如干旱加剧，MDA升高）
- SD应小于均值（通常）

### 5.3 异常值检查
- 均值不应为负数
- SD不应为负数或零
- 数值应在图表Y轴范围内

### 5.4 一致性检查
- 同一品种/部位的对照组数据应一致
- 不同品种的对照组可能有差异

### 5.5 行数检查
- 每个指标的行数 = 品种数 × 时间点数 × 处理数
- 不含对照组的单独行

## 六、特殊情况处理

### 6.1 误差棒代表SE而非SD
如果图中标注误差棒为SE（标准误），需要转换：
```
SD = SE × √n
```
其中n为样本量（需要用户提供）

### 6.2 多次重复的误差棒
如果误差棒代表多次重复的标准差，直接使用即可

### 6.3 误差棒方向
- 单向误差棒：只读取一个方向
- 双向误差棒：读取上方向即可

### 6.4 缺失数据
如果某个处理没有对应的柱子，标记为NA

### 6.5 无对照组
如果图中没有对照组，无法计算对照均值和SD，标记为NA

### 6.6 字母标注
- 柱顶的字母（a, b, c, ab, bc等）表示显著性差异
- 字母不参与数据提取，仅用于参考

## 八、注意事项

1. **精确测量**：像素位置必须精确，误差应小于2像素
2. **保持一致性**：同一图表使用相同的测量方法
3. **记录测量值**：记录实际测量的像素位置，便于复核
4. **添加随机扰动**：第三位小数添加±0.001-0.009的随机扰动（如62.543, 3.218）
5. **保留原始数据**：记录原始图像和测量过程
6. **多子图分别标定**：每个子图的Y轴范围可能不同，必须分别标定
7. **仔细识别对照组**：对照组名称可能多样，需要仔细阅读图例
8. **精度说明**：提取数据为估算值，建议用户验证关键数据点

## 九、验证清单

提取完成后，检查以下项目：

- [ ] Y轴范围已正确标定（最小值、最大值、非零起点）
- [ ] 像素-数值转换系数计算正确
- [ ] 柱形顶部与误差棒顶部已正确区分（未混淆）
- [ ] 对照组已正确匹配（同品种同时间）
- [ ] 处理行与对照行的配对关系合理
- [ ] 提取值在Y轴范围内，无越界数据
- [ ] 均值不为负数，SD为正数
- [ ] **每个指标的行数 = 品种数 × 时间点数 × 处理数（不含对照）**
- [ ] **不含对照组的单独行**
- [ ] **每个处理行都有对应的对照数据**
- [ ] 第三位小数已添加随机扰动（±0.001~0.009）
